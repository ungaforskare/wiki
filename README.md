# wiki

Wiki för Unga Forskares historia. Skapad inför 50-årsjubileumet 2027.

## Bidra

Har du information om Unga Forskares historia? Du är välkommen att skicka
en pull request.

Det spelar ingen roll om du satt i förbundsstyrelsen på sjuttiotalet eller
hittade en pärm på vinden i förrgår. Protokoll, verksamhetsberättelser,
kursprogram, fotografier, tidningsurklipp, egna minnen — allt som säger
något om vad förbundet gjorde och vilka som var med hör hemma här.

Är du osäker på formen, skicka in ändå. Det är lättare att rätta en
felformaterad not än att återskapa en uppgift ingen skrivit ner.

Se [CONTRIBUTING.md](CONTRIBUTING.md) för mer information kring hur du kan bidra.
Se [STYLEGUIDE.md](STYLEGUIDE.md) för konventioner kring hur filer organiseras och struktureras.
